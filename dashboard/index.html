prodrome — signal-to-label latency

Conventional pharmacovigilance tooling reports which drug–reaction pairs are reported disproportionately. This measures something else: how much warning each signal-detection criterion actually buys before the drug label changes — computed point-in-time, so the answer is not contaminated by the labelling event it is trying to predict.

The measurement that motivates this

When a reaction is added to a drug's label, reporting of that reaction rises sharply — clinicians who now know to look for it, report it. This is notoriety bias, and it has a specific methodological consequence: a disproportionality statistic computed on the full cumulative database is partly caused by the label change it would be used to predict. Every open FAERS analysis found while building this computes exactly that statistic.

What each criterion buys, and what it costs

Published signal-detection rules disagree about when a signal starts. The interval-based rules fire earlier and noisier; the MHRA triple fires later and cleaner. Whether that trade is worth making is an empirical question about lead time, shown here against the alarm count each rule raises to achieve it. PRR ≥ 2 with no count or significance gate is included as a negative control on method — it is what a large share of the published FAERS literature applies.

Point-in-time trajectory

A single pair's disproportionality as it was computable at each quarter end, using only reports FDA had received by that date. Where a label change was detected, it is marked — the gap between the first firing and that marker is the lead time this project measures.

Does the prioritisation model actually work

A ranking is only useful if its probabilities mean something and its order beats chance. Both are shown on the held-out period. The split is temporal, not random: a random split would put later quarters of the same pair in training and earlier ones in test, and let the model calibrate against an era it should not have seen.

What the model weights

Cohort

Fifty-five drugs chosen because their labels have moved — each is either a product whose safety labelling demonstrably changed since 2016 or a recent approval under active surveillance, so the outcome variable has both events and genuine right-censored observations. UNII coverage is the measured share of a drug's reports that openFDA harmonised to a substance identifier; where it is low, that drug's reports are found by reporter-supplied name instead, and its figures should be read accordingly.

Method and limits

How a label gap is decided

Each archived label version is parsed into its LOINC-coded sections, and only the primary safety sections count as evidence: boxed warning, contraindications, warnings and precautions, adverse reactions. Clinical studies is excluded deliberately — it runs to 18,000 characters on a typical label and names dozens of adverse events as trial outcomes, so matching against it would mark almost every reaction as already labelled. Indications is excluded because therapeutic goals collide with adverse events: "weight decreased" is both, for a GLP-1 agonist.

Matching runs lexically first — MedDRA uses British spellings and US labels use American, so "diarrhoea" against "diarrhea" and "ischaemic" against "ischemic" are handled by rule rather than by model — then semantically for the residue, such as "intestinal obstruction" against "blockage of the bowel". The semantic layer uses a per-label empirical null rather than a fixed cosine threshold: measured on real labels, raw cosine similarities cluster near 0.62 with a standard deviation of 0.04, so any fixed cutoff either admits nonsense or rejects genuine paraphrase.

What this cannot tell you

These are reporting associations, not risks. FAERS has no denominator, no control group, and no verification of causality. A disproportionate ratio is a hypothesis to evaluate, never evidence that a drug caused a reaction.

A label change is a proxy outcome. It reflects FDA's assessment of accumulated evidence from many sources, most of them not FAERS. Predicting it is useful for prioritising review; it is not the same as predicting whether an association is real.

Left truncation is excluded, not solved. Reactions already described in a drug's earliest archived label version have an unknowable addition date and are dropped from the time-to-event analysis. The count of such pairs is reported alongside every result.

MedDRA's hierarchy is licensed and cannot be redistributed, so there is no System Organ Class grouping here and the clinical synonym table is hand-built and incomplete. Reaction term strings themselves come from public FAERS records.

Only a drug's most-reported reactions are evaluated, capped per drug to stay inside a free API quota. The long tail is a matter of request budget, not of method.

Built on the openFDA adverse event API and DailyMed's Structured Product Label archive — both public, both free. Source and full methodology at github.com/mithinsagar/prodrome.
